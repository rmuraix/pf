# CLAUDE.md

## Implementation

- Write all code comments and docstrings in English, using Google style. Keep comments minimal: only explain non-obvious *why*, never restate *what* the code already says.
- Follow established best practices and idiomatic patterns for the language/library in use; prefer reusing existing utilities and patterns already present in the codebase over introducing new ones.
- Apply DRY, YAGNI and low coupling.

## Git Workflow

- Use conventional commits
- Split PRs by Scope
